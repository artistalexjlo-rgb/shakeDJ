# ShakeDJ

Диджей на ходу: телефон — это пульт. Трясёшь, наклоняешь, тапаешь и тянешь пальцем — трек ремиксуется в реальном времени.

## Жесты

| Жест | Что происходит |
|---|---|
| **Тряхнуть** телефон | Брейк. Режимы по кнопке «Брейк»: **ролл** (бит-репит 1/2 → 1/16), **дроп** (трек пропадает, играет барабанный филл), **стоп** (торможение ленты), **спин** (бэкспин). «Авто» — по кругу. После брейка трек продолжается с того места, где был бы без него (slip), и вступает с бочкой и тарелкой |
| **Наклонить** влево / вправо | DJ-фильтр: влево — низкие частоты (глухо), вправо — высокие (тонко). Около вертикали ±15° фильтр выключен |
| Положить **экраном вниз** | Полный low-pass, «под водой» |
| **Тап** по пластинке | Бочка |
| Тап **вторым пальцем** | Клэп |
| **Тянуть вниз** / вверх | Темп замедляется / ускоряется, пока палец держит; отпустил — плавно возвращается |
| **Тянуть вбок** | Скретч: пластинка идёт за пальцем, остановил палец — остановилась |
| **Держать** палец неподвижно | Луп на одну долю, пока держишь |
| Пэды внизу | Бочка, снейр, клэп, хэт, открытый хэт, перкуссия (срабатывают на касание, без задержки) |
| Кнопка BPM | Тап-темпо; долгое нажатие — вернуть автоопределённый темп |

## Источники звука

- **Свой трек**: любой файл, который умеет декодировать телефон (mp3, m4a/aac, flac, ogg, opus, wav…). Кнопка «Трек…» или «Открыть с помощью / Поделиться → ShakeDJ». Темп определяется автоматически. Работают все эффекты.
- **Поверх стриминга** (Spotify, YouTube Music, Яндекс Музыка…): включи музыку там и открой ShakeDJ. Бочки, пэды и филлы по встряске играют поверх. Android не позволяет приложениям менять чужой звук, поэтому темп, скретч и брейки на стриминге недоступны. Галочка «…и на стриминг (эксп.)» пробует включить фильтр наклоном на общий звук через системный эквалайзер. Часть телефонов это разрешает, часть нет.

## Требования

Android 8.0+ (API 26). Нужен акселерометр; датчик гравитации желателен.

## Сборка

- **GitHub Actions**: каждый пуш собирает debug-APK. Его можно скачать в разделе *Actions → Build APK → Artifacts*.
- **Локально (Gradle)**: `./gradlew assembleDebug` → `app/build/outputs/apk/debug/`.
- **Без Gradle** (там, где Google Maven недоступен): `scripts/build-apk-without-gradle.sh`. Скрипт собирает тот же код через `javac` → `dx`/`d8` → `aapt2` → `apksigner`. Поэтому код написан на Java 8 без лямбд.

Сборки подписываются debug-ключом той машины, где собраны. APK из разных мест не обновляют друг друга: перед установкой APK из другого источника удали старую версию.
