# ShakeDJ

Диджей на ходу: телефон — это пульт. Трясёшь, наклоняешь, тапаешь и тянешь пальцем — трек ремиксуется в реальном времени.

## Жесты

| Жест | Что происходит |
|---|---|
| **Тряхнуть** телефон | Брейк. Режимы по кнопке «Брейк»: **ролл** (бит-репит 1/2 → 1/16), **дроп** (трек пропадает, играет барабанный филл), **стоп** (торможение ленты), **спин** (бэкспин). «Авто» — по кругу. Брейк начинается со следующей доли и длится до ближайшего «раза» (минимум две доли). Трек возвращается на «раз» с бочкой и тарелкой, с того места, где был бы без брейка (slip) |
| **Наклонить** влево / вправо | DJ-фильтр: влево — низкие частоты (глухо), вправо — высокие (тонко). Около вертикали ±15° фильтр выключен |
| Положить **экраном вниз** | Полный low-pass, «под водой» |
| **Тап** по пластинке | Бочка |
| Тап **вторым пальцем** | Клэп |
| **Тянуть вниз** / вверх | Темп замедляется / ускоряется, пока палец держит, **тон не меняется** (растяжение времени WSOLA, как warp в Ableton). Отпустил — сразу исходный темп |
| **Тянуть вбок** | Скретч поверх трека: трек играет дальше (чуть тише), а сверху звучит скретч с доли, на которой ты коснулся. Ход привязан к темпу: вся ширина экрана = пол-доли. Отпустил — скретч затихает, трек уже в своём ритме |
| **Держать** палец неподвижно | Луп на одну долю, пока держишь |
| Пэды внизу | Бочка, снейр, клэп, хэт, открытый хэт, перкуссия (срабатывают на касание) |
| Кнопка **Квант** | Притягивает пэды и тапы к сетке темпа: выкл / 1/16 / 1/8 / 1/4. Удар попадает в долю, в которую ты целился по тому, что слышал. Если задержка звука не даёт успеть, удар уходит в следующую долю сетки. Опоздание до 40 мс звучит сразу. Нужна сетка: трек или BPM, отстуканный с «раза» |
| Ползунок **Пэды** | Громкость ударных, до 200%. На выходе стоит лимитер, так что громко, но без хрипа |
| Ползунок **Сайдчейн** | Насколько удары приглушают трек (сильнее всего бочка). Трек «вдыхает» обратно за пол-доли, то есть качает в темп. Работает для своего трека, стриминг приглушить нельзя |
| Кнопка BPM | Тап-темпо: первый тап отмечает «раз», следующие задают темп. Долгое нажатие — вернуть автоопределённые темп и сетку |
| Кнопка **1** | Нажми на первой доле такта, если автоопределение ошиблось с «разом». Четыре точки над пластинкой показывают текущую долю, красная — «раз» |

## Источники звука

- **Свой трек**: любой файл, который умеет декодировать телефон (mp3, m4a/aac, flac, ogg, opus, wav…). Кнопка «Трек…» или «Открыть с помощью / Поделиться → ShakeDJ». Темп и сетка долей определяются автоматически. Работают все эффекты.
- **Поверх стриминга** (Spotify, YouTube Music, Яндекс Музыка…): включи музыку там и открой ShakeDJ. Бочки, пэды и филлы по встряске играют поверх. Чтобы сбивка попадала в долю, отстучи темп кнопкой BPM, начиная с «раза». Android не позволяет приложениям менять чужой звук, поэтому темп, скретч и брейки на стриминге недоступны. Галочка «…и на стриминг (эксп.)» пробует включить фильтр наклоном на общий звук через системный эквалайзер. Часть телефонов это разрешает, часть нет.

## Задержка

Под точками долей показаны задержка звукового вывода, куда идёт звук (динамик, провод, USB, Bluetooth), через что он выводится и размер буфера. Сначала приложение пробует **AAudio**: это нативный низкозадержочный звук Android (его же использует Oboe), на многих телефонах он даёт MMAP-канал в обход системного микшера. Если AAudio нет (Android 8.0) или он не открылся, используется AudioTrack: по очереди пробуются float, 16-bit и «игровой» тип звука, и берётся вариант, для которого телефон даёт быстрый канал. «Без быстрого пути» значит, что телефон его не дал. При смене выхода звука поток открывается заново.

## Требования

Android 8.0+ (API 26). Нужен акселерометр; датчик гравитации желателен.

## Сборка

- **GitHub Actions**: каждый пуш собирает debug-APK. Его можно скачать в разделе *Actions → Build APK → Artifacts*.
- **Локально (Gradle)**: `./gradlew assembleDebug` → `app/build/outputs/apk/debug/`.
- **Без Gradle** (там, где Google Maven недоступен): `scripts/build-apk-without-gradle.sh`. Скрипт собирает тот же код через `javac` → `dx`/`d8` → `aapt2` → `apksigner`. Поэтому код написан на Java 8 без лямбд.

Сборки подписываются debug-ключом той машины, где собраны. APK из разных мест не обновляют друг друга: перед установкой APK из другого источника удали старую версию.
